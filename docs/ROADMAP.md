# Roadmap / future improvements

## Stage 15B.3 validation
Verify expanded projection at 16:9, 17:9 and 21:9, horizontal culling, HUD anchoring and video proportions. Retain 4:3 and stretch fallbacks.

## Stage 15C — Loading
Map extracted HDD/SSD files to original sector extents; preserve CD commands, IRQ, DMA, completion and seek timing. Preserve Mode2 Form1/Form2 and XA streaming.

## Stage 15D — MDEC
Measure playback and decode scheduling; preserve audio sync; add optional deblocking, deringing, chroma upsampling and scaling.

## Stage 15E — Camera
Locate camera routines; add right stick X/Y, R3 recenter, sensitivity, deadzone and FOV limits; preserve scripted scenes.

## Stage 15F — UI and testing
Integrate Advanced Options into original menus, persistent settings, controller navigation and reproducible Windows builds.
